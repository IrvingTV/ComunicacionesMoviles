Proyecto de Implementación de un Servicio de Comunicaciones Móvil con Riego Automatizado mediante Mallas WiFi

1. Introducción y Problemática a Resolver

Objetivo:

Desarrollar un sistema integrado de comunicaciones móviles que permita controlar y monitorear un sistema de riego automatizado mediante una malla WiFi, optimizando el uso de recursos hídricos y garantizando conectividad en zonas agrícolas con cobertura limitada.

Problemática:

Ineficiencia en el uso de agua en cultivos por métodos tradicionales de riego.
Falta de monitoreo en tiempo real de condiciones ambientales (humedad del suelo, temperatura).
Limitaciones de cobertura en áreas rurales para transmisión de datos.
Necesidad de un sistema escalable y autónomo que integre IoT y comunicaciones móviles.

2. Etapas del Proyecto

Etapa 1: Análisis de Requerimientos y Diseño Conceptual

Actividades:

  1. Investigar las necesidades de riego en cultivos específicos (ejemplo: hortalizas, cereales).
  2. Definir parámetros críticos a monitorear (humedad del suelo, temperatura ambiente, predicción meteorológica).
  3. Identificar limitaciones de infraestructura en zonas rurales (energía, cobertura celular).
  4. Diseñar un diagrama de bloques del sistema integrado (sensores, actuadores, red WiFi, interfaz móvil).

Entregables:

Documento de especificaciones técnicas.
Diagrama de arquitectura del sistema.

Etapa 2: Selección de Infraestructura y Hardware

Componentes Requeridos:

Nodos Sensores/Actuadores:

  • Sensores de humedad del suelo (ejemplo: FC-28). 
  • Sensores de temperatura y humedad ambiental (DHT22). 
  • Módulos WiFi con soporte para mallas (ESP32 con protocolo ESP-MESH). 
  • Actuadores (electroválvulas para control de riego).

Red de Comunicación:

  • Malla WiFi auto-configurable para cubrir grandes áreas.
  • Gateway central (Raspberry Pi) para enlace con la nube.

Plataforma Móvil/Web:

  • Aplicación móvil para Android/iOS (MIT App Inventor o Flutter).
  • Servidor en la nube (AWS IoT, ThingsBoard) para almacenamiento y análisis de datos.

Justificación del Diseño:

  • ESP-MESH: Permite crear redes escalables sin dependencia de un router central, ideal para zonas extensas.
  • Raspberry Pi como Gateway: Facilita el enrutamiento de datos a la nube y la integración con APIs.
  • Sensores de bajo costo: Balancean precisión y accesibilidad para proyectos académicos.

Etapa 3: Configuración de la Red y Protocolos

Procedimiento:

Configuración de la Malla WiFi:

  • Programar los nodos ESP32 con el protocolo ESP-MESH para formar una red jerárquica.
  • Definir un nodo raíz (conectado al Gateway) para enviar datos a la nube.

Programación de Sensores y Actuadores:

  • Desarrollar firmware en Arduino IDE para lectura de sensores y activación de electroválvulas.
  • Implementar lógica de riego basada en umbrales de humedad (ejemplo: activar riego si humedad < 30%).

Integración con la Nube:

  • Usar MQTT o HTTP para enviar datos al servidor en la nube.
  • Configurar alertas móviles (notificaciones push o SMS) usando servicios como Twilio.

Justificación:

  • ESP-MESH vs. Redes Tradicionales: Elimina la necesidad de repetidores, reduciendo costos.
  • MQTT: Protocolo ligero ideal para IoT con bajo consumo de ancho de banda.

Etapa 4: Desarrollo de la Interfaz Móvil y Pruebas

Actividades:

Diseñar una app móvil que muestre en tiempo real:

  • Niveles de humedad y temperatura.
  • Estado de las electroválvulas (abierto/cerrado).
  • Históricos de riego y consumo de agua.

Implementar control manual/automático desde la app.

Realizar pruebas de campo:

  • Verificar estabilidad de la malla WiFi en diferentes distancias.
    Calibrar sensores y ajustar umbrales de activación.

Entregables:

  • APK de la aplicación móvil.
  • Reporte de pruebas con métricas de latencia y tasa de éxito de transmisión.

Etapa 5: Optimización y Documentación Final

Actividades:

  • Implementar algoritmos de ahorro energético (ejemplo: deep sleep en ESP32).
  • Redactar manual de usuario y técnico (instalación, mantenimiento).
  • Presentar resultados en un informe final con análisis de impacto ambiental y económico.

3. Evaluación del Proyecto

Criterios:

  1. Funcionalidad: Sistema operativo con monitoreo en tiempo real y control remoto.
  2. Innovación: Uso de mallas WiFi y enfoque sostenible.
  3. Documentación: Claridad en manuales y justificaciones técnicas.
  4. Presentación: Demostración práctica del prototipo.
