Redes de Malla WiFi

1. Concepto de Redes de Malla WiFi

Definición:

Una red de malla WiFi (WiFi Mesh) es una infraestructura inalámbrica compuesta por múltiples nodos interconectados que colaboran para distribuir la señal de manera uniforme, eliminando puntos muertos y garantizando cobertura continua. A diferencia de las redes tradicionales con un único router, las mallas WiFi permiten que los nodos se comuniquen entre sí para optimizar la ruta de los datos.

Ejemplo:

En una casa de tres pisos, un router convencional en el primer piso podría no cubrir el tercero. Con una malla WiFi, se instalan nodos en cada piso: el primer nodo se conecta al módem, y los otros actúan como repetidores inteligentes, creando una red única sin pérdida de señal.

2. Características Principales

a) Autoorganización y Autocuración

Los nodos detectan automáticamente la topología de la red y eligen la mejor ruta para los datos. Si un nodo falla, la red se reconfigura sin intervención humana.
Ejemplo: En una oficina, si un nodo se desconecta por un corte de energía, los dispositivos se conectan a otros nodos cercanos sin interrupción.

b) Escalabilidad

Pueden añadirse nodos adicionales para ampliar la cobertura o capacidad.
Ejemplo: Un campus universitario agrega nodos en nuevas aulas para cubrir áreas de reciente construcción.

c) Roaming Inteligente

Los dispositivos cambian automáticamente al nodo con mejor señal, manteniendo una conexión estable.
Ejemplo: Al caminar con un smartphone desde el jardín hasta el sótano de una casa, el dispositivo se conecta al nodo más cercano sin cortes en una videollamada.

3. Componentes de una Malla WiFi

a) Nodos Principal y Secundarios

Nodo Principal (Gateway):

Conectado directamente al módem de Internet.

Nodos Secundarios:

Extienden la señal y se comunican entre sí.

Ejemplo:

El sistema Google Nest WiFi incluye un router principal y puntos de acceso secundarios con asistente de voz integrado.

b) Backhaul Dedicado

Canal de comunicación exclusivo entre nodos para evitar congestión. Puede ser por cable (Ethernet) o inalámbrico (banda de 5 GHz o 6 GHz).


Ejemplo: Netgear Orbi usa una banda de 5 GHz dedicada para el backhaul, reservando la banda de 2.4 GHz para dispositivos finales.

c) Software de Gestión

Plataforma que monitoriza el rendimiento, prioriza dispositivos y aplica actualizaciones.
Ejemplo: TP-Link Deco ofrece una app móvil para configurar redes para invitados, bloquear dispositivos o programar horarios de uso.

4. Arquitectura de una Red de Malla WiFi

a) Topología en Estrella vs. Malla

Red Tradicional (Estrella):

Todos los dispositivos se conectan a un único router.

Red de Malla:

Los nodos se interconectan en una red distribuida, formando múltiples rutas.

Ejemplo:

En un centro comercial, una red tradicional tendría puntos muertos en zonas lejanas al router, mientras que una malla WiFi cubre todas las áreas mediante nodos estratégicos.

b) Protocolos de Enrutamiento

Adaptativos:

Usan algoritmos como HWMP (Hybrid Wireless Mesh Protocol) para optimizar rutas.


Ejemplo:

En una fábrica con maquinaria conectada, los nodos eligen rutas que evitan interferencias de equipos industriales.
